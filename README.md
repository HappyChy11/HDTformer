# HDTformer
# HDTformer Source Package

This folder is the open-source code package created for uploading to GitHub.

## Structure

- `hdtformer/` core implementation (config/data/model/engine/metrics/resources/transformer/msdcd/temporal_vector).
- `configs/` method/reproducible configs (`default`, `bnb_multiseed`, `btc_multiseed`, `bnb_yearly`).
- `tools/` added helpers for visualization source data:
  - `export_msdcd_outputs.py`
  - `export_tv_outputs.py`

## Requirements

```bash
python3 -m pip install -r requirements.txt
```

Python packages are:
- numpy
- pandas
- scikit-learn
- torch
- PyYAML
- psutil
- tqdm

## Scope

For inference and visualization preparation, use:
- `tools/export_msdcd_outputs.py`
- `tools/export_tv_outputs.py`

## Export visualization source data (new folder: `visualization_source_data`)

The two scripts below only read checkpoints and export CSV output for plotting, without changing model source.

### 1) MSDCD source data for BNB and BTC

```bash
python3 tools/export_msdcd_outputs.py \
  --source-root /home/chen/HDTformer/HDTformer \
  --checkpoint-root /home/chen/HDTformer/mymodel/checkpoints \
  --output-dir /home/chen/HDTformer/visualization_source_data \
  --seed 12 \
  --samples 3
```

Input:
- Configs: `configs/bnb_multiseed.yaml`, `configs/btc_multiseed.yaml`
- Checkpoints: `HDTformer_*_seed<seed>.pt`

Output:
- `visualization_source_data/MSDCD/BNB/BNB_sample_000_msdcd.csv`
- `visualization_source_data/MSDCD/BTC/BTC_sample_000_msdcd.csv`
- summary: `visualization_source_data/MSDCD/msdcd_summary.csv`

Each sample CSV contains `position`, `global_index`, `timestamp`, `original`, `trend`, `cyclic` and scaled counterparts. (`cyclic` is the seasonal component in code.)

### 2) TV + HEMA source data for BNB

```bash
python3 tools/export_tv_outputs.py \
  --source-root /home/chen/HDTformer/HDTformer \
  --checkpoint-root /home/chen/HDTformer/mymodel/checkpoints \
  --output-dir /home/chen/HDTformer/visualization_source_data \
  --seed 12 \
  --samples 3
```

Input:
- Config: `configs/bnb_multiseed.yaml`
- Checkpoint: `HDTformer_BNB_seed<seed>.pt`
- HEMA windows: 60, 720, 1440 (1h, 12h, 1d with 60/720/1440 steps)

Output:
- `visualization_source_data/TV/BNB/BNB_sample_000_tv_with_hema.csv`
- `visualization_source_data/TV/BNB/tv_summary.csv`

Each sample CSV contains short sequence RV, engineered `hema_1h` / `hema_12h` / `hema_1d`, and periodic features generated by TV parameters (`rv_periodic`, `hema_*_periodic`).
